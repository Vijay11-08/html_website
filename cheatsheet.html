Standard Global Attributes

Global attributes can be specified on almost any HTML element:

Attribute Example Description & Functionality
id id="main-nav" Unique document-wide identifier, used for CSS targeting, JS DOM hooks, and fragment anchors.
class class="btn btn-primary" Space-separated list of CSS styling classes applied to the element.
title title="More information" Advisory tooltip text shown when hovering over the element on desktop browsers.
data-* data-user-id="42" Custom data attributes for embedding private JavaScript application state.
hidden <div hidden> Boolean attribute that prevents the element from being rendered in the browser.
tabindex tabindex="0" Controls keyboard navigation focus order (0 for normal tab flow, -1 for programmatic focus).
contenteditable contenteditable="true" Specifies whether the element's inner text is editable by the user.
spellcheck spellcheck="true" Enables or disables the browser's built-in spellchecker on inputs and text blocks.

Ready-to-Use Boilerplate Templates

Production HTML5 Starter Skeleton (SEO & OpenGraph Ready) 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title | Brand Name</title>
  <meta name="description" content="Brief description of the webpage under 160 characters for search engines.">
  <meta name="author" content="Your Name">

  <!-- OpenGraph / Social Media Metadata -->
  <meta property="og:title" content="Page Title | Brand Name">
  <meta property="og:description" content="Brief summary for social link previews.">
  <meta property="og:image" content="https://example.com/social-card.jpg">
  <meta property="og:type" content="website">

  <!-- Favicon & Stylesheet -->
  <link rel="icon" type="image/svg+xml" href="/favicon.svg">
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <nav>
      <a href="/">Home</a>
    </nav>
  </header>

  <main>
    <h1>Main Page Heading</h1>
    <p>Content begins here.</p>
  </main>

  <footer>
    <p>&copy; 2026 Company Name. All rights reserved.</p>
  </footer>

  <script src="app.js" defer></script>
</body>
</html>
